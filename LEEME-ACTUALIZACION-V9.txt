ACTUALIZACION V9 - Paquete 100% automatico
=============================================

NOVEDADES DE ESTA VERSION:

1. Botones separados "Excel" y "Fotos" (por si los necesitas sueltos,
   como antes) ADEMAS del boton grande dorado.

2. Boton grande "Paquete completo (.bat)":
   Genera UN SOLO ZIP que contiene:
     - fotos/ (todas las fotos, ya clasificadas por nombre)
     - catalogo.xlsx
     - generar_catalogo_final.py
     - subir_placas_final.py
     - EJECUTAR.bat   <- hace TODO con un doble clic
     - INSTRUCCIONES.txt

   En el ordenador, tu tio (o quien sea) solo tiene que:
     1. Descomprimir el ZIP
     2. Doble clic en EJECUTAR.bat
   Ese .bat instala lo necesario, genera el catalogo final, y lanza
   la subida a la web automaticamente, sin escribir ni un comando.

3. Interfaz completamente rediseñada: colores propios de Electronica
   Imperial (azul marino + dorado), tarjetas mas claras, pantalla de
   bienvenida con el logo y "Creado por MCG", y una seccion de Ayuda
   (icono "i" arriba a la derecha) con el paso a paso completo.

COMO GENERAR EL APK:
    npm install       (si hace falta)
    npm run build
    npx cap sync
    npx cap open android
    (y en Android Studio: Build > Build APK(s))
